2. 第一段：设备 → APP（BLE）

参数值

超时配置

4. 第三段：APP → 云端（HTTPS）

参数值
协议HTTPS（TLS 1.3）
认证Bearer Token（JWT）
数据格式JSON + gzip 压缩
超时30 秒
重试3 次，指数退避（2s → 4s → 8s）
批量大小每批最多 50 条 / 500 KB

同步策略

realtime

写入后立即同步
WiFi 环境下使用

batch 默认

每 5 分钟批量同步
平衡功耗与及时性

wifiOnly

仅 WiFi 下同步
节省蜂窝流量

manual

用户手动触发
完全控制

离线处理

网络不可用时：数据正常写入 SQLite（sync_status = pending）。UI 正常显示本地数据。网络恢复后自动按 received_at 顺序批量同步积压数据。超过 1000 条时分批上传（每批 50 条）。

冲突解决

场景策略
相同 reading.id 重复上传幂等去重，以先到为准
同一时间段不同设备的值全部保留，云端也做融合
家庭成员信息冲突Last Write Wins（updated_at 最新的为准）

5. 数据安全

链路加密认证
设备 → APP (BLE)BLE 配对加密UniqueAppID 鉴权
APP → 云端 (HTTPS)TLS 1.3JWT Bearer Token
APP 本地存储iOS 沙盒保护—
云端存储AES-256（ECG/血糖等高敏感数据）访问控制

数据敏感度分级

高敏感

ECG 波形 · 血糖值 · 血压
传输时额外加密 payload
云端 AES-256 加密存储

中敏感

心率 · 血氧 · 睡眠 · 情绪
标准 HTTPS 传输

低敏感

步数 · 卡路里 · 距离
标准传输

脱敏规则：profileId 用 UUID（不用手机号）· 云端不存 MAC 地址明文（哈希）· 日志不打印原始健康数据值
