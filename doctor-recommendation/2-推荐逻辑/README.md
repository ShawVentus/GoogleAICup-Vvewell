# wewell 医生级推荐器（深圳，MVP）

病情描述 → 31 个标准科室 → **3 家医院 × 每家最多 2 位医生** → 模板解释 + 模型写的开场说明。
规则与验收见 `docs/需求文档-医生级推荐MVP-v2.md`，字段见 `docs/数据结构说明-医生级推荐MVP-v2.md`。
这是从 `../recommender`（17 家医院级系统）复刻出来的独立副本，旧系统不受影响。

## 跑起来
```
python tools/build_doctors.py          # 原始名单 → data/doctor.csv + docs/入库质量报告.md
python tests/test_doctor.py            # 不调模型的确定性测试
export LLM_URL=... LLM_MODEL=...       # 或 ../.env 里的 AI_GATEWAY_API_KEY（Vercel Gemini）
python tests/accept_9.py               # 需求文档第 8 节 9 条验收（调真实模型）
python server.py 8081                  # 网页 http://127.0.0.1:8081/
```

## 数据（562 位医生，5 家医院）
入库规则：公立医院只收主任医师；港大收顾问医生、明写主任医师、「高级医生」；擅长原文为空的不收；归不了类的、麻醉/影像/急诊/重症等不收。
被剔除的人和原因在 `data/doctor_dropped.csv`；各科室人数与缺口在 `docs/入库质量报告.md`。
擅长写「抑郁、焦虑、心理治疗」的医生同时归入 PSY（用户确认）。

## 推荐算法（`recommender.py::retrieve_doctors`）
候选：标准科室与解析结果有交集，再按年龄过滤。排序逐级比较（元组字典序，同输入同输出）：
① 病种关键词命中数（擅长原文或科室名，≥2 字）② 科室名直接归到首选科室 > 仅擅长里提到 > 也合理科室
③ 所在科室为国家级/省级认定 ④ doctor_id。医院名次 = 其最靠前医生的名次，取前 3 家，每家前 2 位。
医院不足 3 家时用科室级推荐补足（只给挂号科室）。

## 展示
医生自称的「顶级」等词展示时清理（`SHOW_SUB`），库里原文不改。已删除：3+1、首诊/确诊、按医院等级排序、国际部接诊方式。
