# wewell 医生级推荐（2026-10-18）三件套

1-前端代码：Flutter 工程。flutter pub get → flutter run / flutter build apk --release。数据来自 assets/demo.json（演示用，不联网）。
2-推荐逻辑：Python（recommender.py 解析→医生检索排序→解释；server.py；tools/build_doctors.py 入库脚本；tests）。运行时从 ../3-数据 的 data 目录读取，放置时把 3-数据 重命名/复制为 2-推荐逻辑/data。
3-数据：doctor.csv（761 位医生，9 家医院）、doctor_dropped.csv（剔除清单与原因）、hospital.csv、hospital_dept.csv、std_dept.csv、raw/（原始名单）、入库质量报告.md。

数据口径：公立医院只收主任医师；港大收顾问医生/明写主任医师/高级医生；新风和睦家收主任医师和有擅长的香港/特聘医生；擅长原文为空、麻醉/影像/急诊/重症、归不了类的不收；二院用新名单并回填旧名单的官网擅长原文；擅长写抑郁焦虑的同时归入精神心理科。

状态：不调模型的确定性测试通过；9 条需求验收在 562 人的库上 9/9 通过，并入新 4 家医院后因模型接口无响应未重跑。不含任何密钥。
